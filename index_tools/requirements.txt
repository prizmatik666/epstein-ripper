# ============================================================
# Epstein DB Utilities — Requirements
# ============================================================
#
# Python version:
#   Python 3.9 or newer is required.
#
# No external pip packages are required.
#
# IMPORTANT:
# These tools use the built-in Python 'sqlite3' module.
# Most Python installations include it automatically.
#
# If you receive:
#   ModuleNotFoundError: No module named 'sqlite3'
#
# On Ubuntu / WSL install:
#   sudo apt install sqlite3 libsqlite3-dev
#
# Then ensure your Python build includes sqlite support.
#
# ============================================================
